# Caeser v7 — Go-first CI failure triage

v7 packages the current Caeser engine and GitHub integration as a prebuilt
Linux amd64 release. The default workflow downloads and verifies the binary
instead of rebuilding Caeser for each failed run.

## Install

For automatic PR reports, add the
[reusable workflow](https://github.com/caeser-org/ceaser/blob/v7/docs/ci-integration.md)
to your repository. It reads a failed run, publishes one updated PR comment,
and uploads the JSON report and Markdown brief.

For a custom GitHub Actions job:

```yaml
steps:
  - uses: caeser-org/ceaser@v7
  - run: caeser version
```

The setup action installs the CLI only. It requires Linux x86_64. GitHub-hosted
Ubuntu 24.04 is the release build and validation environment. Neither path
requires Blacksmith or an AI provider.

## Included

- Go test, assertion, panic and race evidence, with observed source locations
  separated from inferred implementation leads.
- Candidate selection from localized implementation functions, with bounded
  SSA analysis and stack/coverage source fallbacks.
- Short PR comments, expandable detailed evidence, and offline Markdown brief
  export, including a paste-ready prompt format.
- Optional model analysis with bounded source retrieval at the failing revision.
- Explicit runtime probes and retained-binary Go verification, both experimental.
- Updated architecture, setup, reporting and contributor documentation.

## Limits

Go is the current alpha adapter; other language adapters are planned. A source
lead is not a verified root cause. The frozen 16-case probe rerun verified zero
mechanisms. Default log-based reports defer local reproduction when usable CI
failure evidence exists. See the
[evaluation records](https://github.com/caeser-org/ceaser/blob/v7/docs/diagnosis-evaluation.md).

The prebuilt binary removes Caeser's own build step. Target repositories can
still require dependency setup and test compilation. The binary uses CGO and
glibc; other platforms need a source build. The starter workflow excludes forks.

Release assets include `caeser_linux_amd64`, `SHA256SUMS`, and `BUILD_INFO.txt`.
Verify the checksum before executing a manual download.
